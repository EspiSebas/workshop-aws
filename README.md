☁️ Examen Práctico AWS
📋 Descripción

Este repositorio contiene las evidencias del examen práctico realizado en Amazon Web Services (AWS).

Durante el examen se realizaron las siguientes actividades:

Crear un par de claves.
Lanzar una instancia EC2 como servidor web.
Conectarse a la instancia Linux mediante SSH.
Crear un volumen EBS con Tags y asociarlo a la instancia.
Crear un bucket S3 con Tags y subir un archivo .txt.
Documentar y subir las evidencias al repositorio de GitHub.
